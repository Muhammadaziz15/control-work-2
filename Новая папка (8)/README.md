# DigitalHub

Учебный многостраничный сайт на Django. Приложения `pages` и `config` отвечают
за страницы сайта и редактируемые данные компании и услуг.

## Запуск

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Сайт открывается по адресу `http://127.0.0.1:8000/`, панель управления —
`http://127.0.0.1:8000/admin/`.

При миграции база автоматически заполняется демонстрационной информацией
DigitalHub и тремя услугами из HTML-шаблона. Перед публикацией замените
примерные адрес, телефон, email и ссылки на соцсети на свои в админ-панели.
Там же можно изменить описание и услуги. Новые заявки с формы сохраняются в
разделе «Заявки» панели управления. Загруженные логотип и изображения хранятся
в `media/`.

## Страницы

- `/` — главная;
- `/about/` — о проекте;
- `/services/` — услуги из базы данных;
- `/contact/` — контакты компании.

Общие header и footer подключаются через шаблоны `templates/includes/`.
Вёрстка использует CSS и JavaScript из архива HTML-шаблона в `static/css/` и
`static/js/`. Изображения сайта находятся в `static/images/`, загруженные через
админ-панель изображения — в `media/`.

Контактная форма сохраняет заявки в базе данных и доступна без настройки почты.
Для отправки уведомлений на email компании задайте переменные окружения
`EMAIL_HOST`, `EMAIL_PORT`, `EMAIL_HOST_USER`, `EMAIL_HOST_PASSWORD`,
`EMAIL_USE_TLS`, `EMAIL_USE_SSL` и `DEFAULT_FROM_EMAIL`. Без SMTP заявка всё
равно будет сохранена и видна в админ-панели.
